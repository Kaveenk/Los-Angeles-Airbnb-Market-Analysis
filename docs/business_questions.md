# Business Questions

## Project Objective

The objective of this project is to analyze the Los Angeles Airbnb market using listing, calendar, and review data to better understand market size, geographic concentration, guest engagement, host activity, and listing availability.

The analysis is organized around four main areas:

1. Market Overview
2. Neighborhood & Geographic Analysis
3. Reviews & Guest Engagement Analysis
4. Host & Availability Analysis


## 1. Market Overview

This section provides a high-level view of the Los Angeles Airbnb market.

Business questions:

- How many Airbnb listings are included in the dataset?
- How many unique hosts operate within the market?
- How many reviews have Airbnb listings received?
- What is the average number of available days across listings?
- How are listings distributed across different room types?
- Which neighborhoods contain the largest number of listings?
- How does Airbnb availability change throughout the calendar period?


## 2. Neighborhood & Geographic Analysis

This section examines how Airbnb activity varies geographically across Los Angeles.

Business questions:

- How many neighborhoods are represented in the dataset?
- Which neighborhood contains the highest number of Airbnb listings?
- Where are Airbnb listings geographically concentrated?
- How are different room types distributed geographically?
- Which neighborhoods have received the highest total number of reviews?
- Which neighborhoods generate the highest number of reviews per listing?
- How does applying a minimum listing threshold help identify meaningful neighborhood-level engagement?


## 3. Reviews & Guest Engagement Analysis

This section uses historical review activity as an indicator of guest engagement.

Business questions:

- How many total reviews are represented in the dataset?
- How has review activity changed over time?
- Which year recorded the highest number of reviews?
- How many reviews were recorded during the peak review year?
- Which month historically receives the highest review activity?
- How does review activity vary across months?


## 4. Host & Availability Analysis

This section examines host concentration, host portfolio size, review activity, and listing availability.

Business questions:

- Which host manages the largest number of listings?
- How many listings does the largest host manage?
- Which hosts manage the largest Airbnb portfolios?
- Which host has received the highest total number of reviews?
- Which hosts have accumulated the most reviews?
- How are hosts distributed by portfolio size?
- What proportion of hosts operate a single listing compared with multi-listing portfolios?
- How does listing availability vary across the calendar period?


## Analytical Goal

The overall goal is to transform raw Airbnb data into actionable market insights and demonstrate an end-to-end analytics workflow using PostgreSQL, SQL, Power BI, and data visualization.
